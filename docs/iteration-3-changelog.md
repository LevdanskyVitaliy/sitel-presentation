## 3. Новая страница platforms/speech-analytics.html

Структура по блокам (восстановлена из драфта презентации и существовавшего контента главной; скриншот с блочной структурой до команды не дошёл — при расхождениях правится по нему):

1. **Hero** — «Речевая аналитика с суверенитетом данных» + метрики 95% / ≥90% / <1 сек / 100% звонков + CTA.
2. **Двухуровневая модель** — Уровень 1 «работает всегда» (8 пунктов) vs Уровень 2 «по подключению» (6 пунктов); формулы «детектор / диагност».
3. **Модули продукта** — аккордеон (аналитика 100% звонков, ИИ-голосовой помощник, скоринг, дашборды, расширенная аналитика v2.0).
4. **Интерфейс** — прототипы «Карточка звонка» и «Рейтинг операторов» (бэйджи «ПРОТОТИП»).
5. **Карточка звонка до/после** — таблица сравнения с честными ⏳.
6. **Контуры А/Б/В** — три карточки с примерами и совместимостью форм.
7. **Оборудование** — «сервер + одна RTX 4090», крупные цифры 1 × RTX 4090 / 0 ₽ + ссылка на 3D-схему.
8. **CTA** — тёмная полоса «Покажем речевую аналитику на ваших звонках».

## 4. 3D-левитирующая схема архитектуры (architecture.html#scheme)

Новая секция сразу после hero страницы «Архитектура»: изометрический стек из 6 CSS-плит (без картинок, чистый CSS transform rotateX(57°) rotateZ(45°)):

1. Каналы и данные (телефония, CRM, 1С, мессенджеры)
2. Конвейер Уровня 1 на CPU (ASR 95%, NLU ≥90%, эмоции, правила)
3. **Векторная БД pgvector** — акцентная синяя плита с подсветкой (ядро)
4. Малая языковая модель (RTX 4090, ваш GPU)
5. Дашборды и отчёты
6. **Уровень 2 — LLM 32B+** — отдельный «левитирующий остров» с пунктирной рамкой, соединённый пунктиром «обезличенные тексты → оценки · аудио не передаётся»

Детали реализации: плавная левитация плит (keyframes translateY, задержки по слоям), номера слоёв 1–6 на левых вершинах плит, боковые карточки-подписи с чипами (слева/справа поочерёдно), пунктирные линии-связки, легенда, свечения под стеком. Адаптив: ≤980px схема заменяется плоским вертикальным списком слоёв; `prefers-reduced-motion` гасит анимацию (существующее правило).
