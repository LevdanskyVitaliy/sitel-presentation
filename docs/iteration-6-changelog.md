# Итерация 6 — схема-граф со связями (вместо плоских колонок)

Дата: 28.09.2026 · Основание: фидбек заказчика по итерации 5 — раскладка «колонки + гексагон» выглядит плоско; нужна схема **в форме связей** (узлы, соединённые линиями со стрелками), при этом всё линейное в обработке — остаётся линейной цепочкой. Референс-изображения до сервера снова не дошли (3-й раз), схема собрана по текстовому описанию.

## Что изменилось (architecture.html, секция #scheme — только десктоп ≥981px)

- **Канва-граф** 1200×700 (масштабируется JS под ширину контейнера, `transform: scale`): фон — точечная сетка (blueprint) + радиальное свечение под ядром, рамка-карточка.
- **Узлы** — компактные карточки с якорями-точками подключения:
  - слева (вход, серые): Телефония и мессенджеры, CRM · 1С · биллинг, База знаний;
  - центр — **линейная цепочка** конвейера: ASR → NLU → Эмоции и метрики (стрелки в линию);
  - ядро-хаб — **Векторная БД pgvector** (крупный градиентный узел со свечением);
  - над ядром: Малая LLM — ваша GPU (синий), LLM 32+ млрд · подписка (бирюзовый пунктир);
  - под ядром: Хранилище — три слоя; справа (исходы, зелёные/синие): Действия в 1С · CRM, Голосовой бот, Дашборды и отчёты.
- **Связи — SVG-кривые Безье**, строятся JS-ом по фактическим позициям узлов (якоря left/right/top/bottom с долями): стрелки-маркеры по цветам, точки подключения в начале линий, подписи с белым ореолом («резюме · да/нет», «обезличенные тексты», «ответ клиенту < 1 сек»).
  - CRM и База знаний подводятся к нижней грани ядра обходными дугами (под цепочкой);
  - Малая LLM и LLM 32+ — двунаправленные связи сверху (LLM 32+ — пунктир);
  - Хранилище → Дашборды, ядро → Бот/Действия;
  - **дуга возврата** Голосовой бот → Телефония поверх канвы — «ответ клиенту < 1 сек» (цикл замкнут);
  - на линейном конвейере и связи с хранилищем — анимация бегущего пунктира (отключается при `prefers-reduced-motion`).
- Мобильная вертикальная цепочка (≤980px) не изменилась — она уже линейная, как и просил заказчик.
